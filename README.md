# Claude Code with FHRouter

FHRouter provides access to Claude, GPT, and Gemini models through one API key and a prepaid balance. Check the [current catalog](https://fhrouter.com/pricing) for model availability, supported endpoints, and prices. Requests use your account balance; these examples do not include free inference.

Copy the example `env` settings from [settings.json](settings.json) into your Claude Code user settings and replace `YOUR_FHROUTER_KEY` locally. Select an available Claude model using the [setup guide](https://fhrouter.com/docs/guides/claude-code).

Do not commit a settings file containing your real key. Features depend on the selected model and endpoint.
